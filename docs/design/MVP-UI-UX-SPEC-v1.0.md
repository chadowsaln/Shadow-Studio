## 0. النطاق وغير النطاق

### 0.1 داخل النطاق (بعمق تصميمي كامل)

| # | السطح | لماذا |
| --- | --- | --- |
| S1 | **Timeline**: مسارات، مقاطع، zoom، snapping، trim/split/join، multi-select، كيبورد | قلب المنتج؛ لا يوجد بديل مقبول |
| S2 | **Preview**: تشغيل، scrub، safe area، جودة، معالجة الأخطاء | الحكم البصري على كل تعديل |
| S3 | **Export**: اختيار preset، pre-flight، تقدّم، فشل، استئناف | نهاية الرحلة؛ أكثر مكان يخسر فيه المستخدم ثقته |

### 0.2 داخل النطاق بشكل مساند (أقل عمقاً، بلا تفاصيل بصرية كاملة)

Media bin والاستيراد، Inspector، تحرير النص العربي، مراجعة مقترح AI، شريط الحالة، لوحة الإعدادات.

### 0.3 خارج النطاق

Color grading، keyframe editor متقدم (منحنيات)، collaborative، mobile، text-to-video، cowatching. وتحسينات تتطلب قدرات محرك غير موجودة في `SS-ARCH-001` (مثل ripple trim متعدد المسارات، nesting، multicam) — تُذكر كـ «مؤجّل» مع السبب، لا تُصمَّم.

### 0.4 حدود التصميم الملزمة (من المعمارية)

| القيد | المصدر | أثره على التصميم |
| --- | --- | --- |
| 60 fps في الواجهة، scrub ≤ 120 ms p95 | §1.3، §7.5 | لا تخطيط ثقيل أثناء السحب؛ لا spinner يغطّي preview أثناء scrub |
| Preview = بث HTTP عام لا محرك | §2.4، §د.1 | الواجهة لا تعرض «إطاراً حقيقياً» قبل أن يصل؛ تُظهر آخر إطار مع حالة |
| لا تداخل مقاطع على المسار | §3.4 (V-07) | الإفلات فوق مقطع ليس overwrite صامتاً: إمّا ripple (batch أوامر) أو منع واضح |
| Undo = batch واحد لكل معاملة | §3.5.2 | كل حركة إفلات/trim = خطوة undo واحدة |
| أوامر محدودة معلومة | §3.5.1 | لا زر ينتج أمراً غير موجود (مثلاً «ripple delete» غير معروض) |
| حالة المهمة موحّدة | §د.5 | شريط تقدّم واحد للمفاهيم: queued/running/succeeded/failed/cancelled/interrupted |
| النص = raster من الخلفية | §4.4 | محرّر النص WYSIWYG بحدود: يُعاد الرسم في الخلفية؛ لا معاينة نص محلية |
| مفاتيح AI لا تُخزَّن في التطبيق | §6.2 | شاشة AI تعرض CTA للإعداد، لا تعمل بلا مفتاح |

## 1. المبادئ وأهداف التجربة

| # | المبدأ | كيف يُختبر عملياً |
| --- | --- | --- |
| P1 | **المعاينة هي الحقيقة** | ما يُعرض بعد القبول النهائي هو ما يُصدَّر (نفس rasters، نفس الترتيب) |
| P2 | **لا أوضاع خفية** | لا tool modal؛ كل ما تفعله الأداة معروض بالمؤشّر والحالة |
| P3 | **القابل للتراجع قبل التحذير** | أي تعديل قابل للتراجع لا يسأل «هل أنت متأكد؟» |
| P4 | **الصدق في الانتظار** | لا تقدّم مزيف ولا ETA ملفّق؛ لأنظمة الوقت «—» مقبولة |
| P5 | **العربية أولاً، والمحور زمني** | كل النصوص والاتجاه RTL؛ محور الزمن LTR (قرار §2.4) |
| P6 | **الكيبورد مواطن أول** | كل عملية أساسية لها اختصار، وكل اختصار معروض في مكان ما |
| P7 | **الفشل يُشرح ويُعالج** | كل خطأ: ماذا حدث، هل يُعاد، وما الزر التالي |

**هدف التجربة (واحد، قابل للقياس):** مستخدم جديد يُنتج مقطعاً مدته 60 ثانية (استيراد → قصّ → عنوان → تصدير) في **≤ 7 دقائق** دون فتح مساعدة، ودون سؤال «هل انتهى التصدير؟» أكثر من مرة.

## 2. نظام التصميم (Design System)

### 2.1 الرموز (Semantic Tokens)

لا يُستخدم hex مباشرة في أي widget؛ تُستخدم الرموز. القيم أدناه مقاسة فعلياً بنسبة تباين WCAG (نُسب محسوبة، لا مقدّرة) — الحد المطلوب: **4.5:1 للنص**، **3.0:1 للعناصر الرسومية ذات المعنى**.

| Token | Dark (افتراضي) | Light | يُستخدم في |
| --- | --- | --- | --- |
| `surface-0` | `#0E0F12` | `#FAFAFB` | خلفية النافذة، خلفية الـ timeline |
| `surface-1` | `#16181D` | `#FFFFFF` | لوحات، حوارات |
| `surface-2` | `#1E2229` | `#F1F2F5` | رؤوس المسارات، شرائط الأدوات |
| `border` | `#2A2F38` | `#D8DBE0` | فواصل زخرفية (غير كافية وحدها للدلالة) |
| `text-primary` | `#ECEDEF` | `#14161A` | نصوص أساسية |
| `text-secondary` | `#AEB6C2` | `#4A5361` | تسميات ثانوية |
| `text-muted` | `#7C8696` | `#6B7482` | meta/timecode خامل |
| `accent` | `#6A4DFF` | `#5B3DE6` | إجراء أساسي، focus ring، تحديد |
| `on-accent` | `#FFFFFF` | `#FFFFFF` | نص على accent |
| `playhead` | `#FF4D4D` | `#D92B2B` | playhead وخطه |

| `track-video` | `#2B3A55` | `#DCE6F5` | جسم مسار الفيديو |

**نسب التباين المحسوبة (dark):** `text-primary/surface-1` = 15.16، `text-secondary/surface-1` = 8.68، `text-muted/surface-1` = 4.83، `on-accent/accent` = 5.10، `danger/surface-1` = 6.40، `warning/surface-1` = 8.70، `success/surface-1` = 10.05، `playhead/surface-2` = 4.88، `selection/surface-2` = 8.68.
**(light):** `text-primary/surface-1` = 18.11، `text-secondary/surface-1` = 7.77، `text-muted/surface-1` = 4.72، `on-accent/accent` = 6.45، `danger/surface-1` = 6.57، `warning/surface-1` = 5.93، `success/surface-1` = 5.37، `playhead/surface-2` = 4.33 (عنصر رسومي ≥ 3.0 ✅ / نص ❌ فلا يُستخدم كنص)، `selection/surface-2` = 4.84.

`border` لا يُستخدم أبداً كدلالة وحيدة (تباينه 1.32)؛ كل حدّ ذي معنى يصحبه لون أو أيقونة أو نص. و`text-muted` **لا يُستخدم على `surface-2`** (4.34 < 4.5)؛ للنص الخامل على رؤوس المسارات يُستخدم `text-secondary` (7.80).

### 2.2 الطباعة

| الدور | الخط | الحجم/الوزن | الاستخدام |
| --- | --- | --- | --- |
| Display | Cairo | 24/600 | عناوين الحوارات |
| Title | Cairo | 16/600 | رؤوس اللوحات |
| Body | Cairo | 13/400 | كل النصوص التشغيلية |
| Numeric | IBM Plex Mono | 12/500 | timecode، أرقام فقط (منع انعكاس الأرقام في RTL) |
| Caption | Cairo | 11/400 | meta، مسارات |

أرقام وتايم كود دائماً بخط `Numeric` واتجاه `LTR` معزول (`U+2066 … U+2069`) لمنع انعكاس `00:00:04:12` في سياق عربي.

### 2.3 المسافات والحركة

- سلّم مسافات 4px: `4 / 8 / 12 / 16 / 24 / 32`.
- ارتفاع الصف الأساسي 32px؛ أهداف النقر ≥ 32×32، ومقابض الـ trim 8px مرئية + 12px hit area.
- الحركة: 120 ms للظهور، 180 ms للألواح، `prefers-reduced-motion` → 0 ms. لا حركة على playhead أو أثناء scrub مطلقاً.

### 2.4 اتجاه الواجهة (قرار مسجّل)

**قرار:** الواجهة RTL بالكامل (اللوحات، الحوارات، القوائم)، **لكن محور الزمن في الـ timeline يبقى LTR**: الزمن يتقدّم يساراً→يميناً، وpreview/timeline لا يُمرَّران.

**السبب:** محور زمني معكوس يكسر الذاكرة العضلية لكل مرجع تحرير، ويقلب معنى «السابق/التالي» في trim وkeyframes، ويضاعف احتمال أخطاء الإشارة في الحسابات.
**البديل المرفوض:** مرآة كاملة للـ timeline — صراحةً مرفوض لأنه يجعل `source_in` واتجاه السحب يتعارضان مع كل توثيق وأداة.

ما يُمرَّر فعلياً: ترتيب اللوحات، أيقونات الإجراءات، شريط الأدوات، اتجاه النص، وحواف الأزرار (radius على اليسار/اليمين حسب RTL). وما لا يُمرَّر: محور الزمن، بكسلات الصورة في preview، والرسوم البيانية.

## 4. نموذج الحالة والتنقّل

### 4.1 الحالات العامة

| الحالة | متى | ما يراه المستخدم |
| --- | --- | --- |
| `No project` | بداية التشغيل | شاشة بدء: `مشروع جديد` / `فتح` / `آخر المشاريع` |
| `Opening` | أثناء `POST /projects/open` | skeleton للتخطيط، تعطيل الإدخال، لا spinner يغطّي كل شيء |
| `Ready` | المشروع مفتوح | الواجهة الكاملة |
| `Recovering` | فقد WS / إعادة تشغيل Core | حوار modal واحد: ما حدث + `إعادة المحاولة` + `فتح نسخة` |
| `Read-only` | فشل الكتابة على القرص | كل التعديل يُعطَّل، شريط علوي `⚠ للقراءة فقط` |

### 4.2 التحويلات (مبسّطة)

```text
No project ──new/open──► Opening ──ok──► Ready
                              └─fail──► No project + problem toast
Ready ──ws lost──► Recovering ──ok──► Ready
Ready ──disk read-only──► Read-only ──fixed──► Ready
```

### 4.3 قواعد التغذية الراجعة

1. **كل أمر كتابة** يحمل `If-Match: revision`؛ عند `409 CONFLICT_REVISION_MISMATCH` لا نعيد المحاولة تلقائياً: نحدّث الـ timeline من `GET /timeline` ونعرض toast `تم تحديث المشروع من مصدر آخر` (نادر: AI/import).
2. **التراجع** يُظهر toast باسم الإجراء (`تم التراجع: قصّ`) مع `Ctrl+Z`، ويختفي بعد 4 ثوانٍ بلا سرقة تركيز.
3. **الحفظ:** تلقائي بعد 2 ثانية خمول أو 20 عملية؛ المؤشر `حفظ ✓` مع وقت نسبي.
4. **الحركات** لا تُعرض على أنها حفظ: الحفظ حالة منفصلة.

## 5. Timeline — التصميم التفصيلي

### 5.1 التشريح (Anatomy)

| العنصر | الارتفاع | التفاعل |
| --- | --- | --- |
| Ruler | 28px | click = نقل playhead؛ drag = scrub؛ double-click = zoom to fit |
| Track header | 56px (قابل 40–160) | click = تحديد المسار؛ أيقونات M/S/🔒/▣؛ سحب الحافة السفلية = ارتفاع |
| Track lane | نفس الرأس | المقاطع + فراغ قابل للنقر |
| Playhead | — | سحب من أي مكان في الرأس أو المسطرة |
| Toolbar | 40px | تحديد/razor، snap، zoom، timecode |

### 5.2 المقطع (Clip) — ما يُرسم ومتى

| Zoom (px/s) | داخل المقطع |
| --- | --- |
| < 8 | لون + label فقط (بلا صور) |
| 8–20 | label + شريط waveform مصغّر للصوت |
| 20–80 | thumbnails (كل 2s) + waveform |
| 80–240 | thumbnails (كل 0.5s) + frame lines |
| > 240 | إطار لكل إطار + ticks على المسطرة |

قواعد الرسم:

1. **العرض الأدنى** للمقطع 2px؛ ما دون ذلك يُرسم كخط متصل مع عدّاد عند التحديد.
2. **حدود المصدر:** عند `source_in > 0` أو الوصول لنهاية المصدر، يُرسم مثلث صغير على الحافة (مؤشر «لا مزيد»). الوصول لنهاية المصدر يمنع trim إضافياً بلا رسالة (المؤشر يتغير).
3. **أثر التعديل:** مقاطع `speed ≠ 1` تحمل شارة `1.5×`؛ المقاطع المعطّلة (`enabled=false`) تُرسم بـ 35% شفافية + خط مائل.
4. **مفقود:** أصل غير موجود → المقطع بإطار `danger` متقطع + أيقونة تحذير + `relink` في الـ inspector.
5. **proxy غير جاهز:** شارة `◌` صغيرة على المقطع؛ لا يمنع التحرير، ويمنع فقط preview سلساً (يُستخدم الأصل).

### 5.3 Zoom والتمرير

| الإجراء | المدخل |
| --- | --- |
| Zoom حول المؤشر | `Ctrl/Cmd + wheel` |
| Zoom رأسي (ارتفاع المسارات) | `Alt + wheel` |
| تمرير أفقي | `Shift + wheel` / trackpad أفقي |
| Fit sequence | `Z` أو double-click على المسطرة |
| Zoom to selection | `Shift+Z` |
| Zoom ladder | `=` / `-` ينتقل بين 8 مستويات log: 2، 5، 10، 20، 40، 80، 160، 320 px/s |

**قاعدة التثبيت:** point تحت المؤشر يبقى ثابتاً أثناء zoom (لا قفز). عند `zoom < 10 px/s` يُقلَّص الرسم إلى ملخص (label فقط) لتظل 60 fps مع 2000 clip.

### 5.4 التحديد

| الإجراء | النتيجة |
| --- | --- |
| click | تحديد مقطع واحد |
| `Shift+click` | إضافة/إزالة من التحديد |
| marquee على فراغ | تحديد كل ما يتقاطع |
| click على رأس المسار | تحديد كل مقاطع المسار |
| `Ctrl/Cmd+A` | كل المقاطع في التسلسل المحدد |
| `Esc` | إلغاء التحديد |
| `↑/↓` | نقل التحديد إلى المقطع المجاور على نفس المسار |

**Inspector متعدد:** عند تحديد أكثر من مقطع يُعرض عدد + الحقول المشتركة فقط؛ تعديل حقل يُطبَّق كـ batch واحد (خطوة undo واحدة).

### 5.5 السحب والإفلات

```text
1. press على مقطع → انتظار 3px قبل بدء drag (منع النقرات المهتزة)
2. drag: ghost بشفافية 60% + خط عمودي للـ snap target
3. snap: مسافات ≤ 8px إلى (حدود المقاطع، playhead، markers، بداية التسلسل، شبكة الإطارات)
   - مؤشر snap: خط accent + tooltip بالفرق (مثلاً «+00.00.00.12»)
   - تعطيل مؤقت: Alt أثناء السحب
4. drop على فراغ → clip.move
5. drop فوق مقطع آخر على نفس المسار → سلوك ripple:
     batch = [clip.insert(at=drop), clip.move(كل ما بعد نقطة الإفلات +duration)]
     (أوامر موجودة في §3.5.1؛ لا أمر محرك جديد)
     - ghost يتحول للون accent + نص «إدراج وإزاحة» قبل الإفلات
6. drop بين مسارين مختلفي النوع → ممنوع: مؤشّر ✕ + tooltip «مسار صوت لا يقبل فيديو»
7. drop على مسار مقفل → ممنوع: ✕ + اهتزاز خفيف للرأس
```

**قاعدة صارمة:** لا overwrite صامت أبداً (يخالف V-07). إمّا إدراج بإزاحة معلنة، أو منع واضح.

### 5.6 Trim و Split و Join

| العملية | التفاعل | الأمر | ملاحظات |
| --- | --- | --- | --- |
| Trim in | سحب الحافة اليسرى | `clip.trim` | يحافظ على نهاية المقطع؛ لا يتجاوز `source_in ≥ 0` |
| Trim out | سحب الحافة اليمنى | `clip.trim` | لا يتجاوز مدة المصدر |
| Slip (نفس المدة، مصدر مختلف) | `Alt+drag` على المقطع | `clip.trim` (in+out معاً) | ghost يعرض الإطار الجديد |
| Split عند playhead | `S` أو زر Razor | `clip.split` | يطبَّق على كل المحدد؛ إن لم يوجد تحديد → على كل المسارات غير المقفلة |
| Split عند المؤشر | `Shift+S` | `clip.split` | يُحدد tick من موضع المؤشر |
| Join | `Ctrl/Cmd+J` على مقطعين متجاورين من نفس الأصل والسرعة | `clip.join` | معطّل (رمادي) إن اختلف الأصل أو السرعة، مع tooltip السبب |
| Delete (lift) | `Delete` | `clip.delete` | يترك فراغاً؛ قابل للتراجع |
| حذف بإزاحة | **غير معروض** | — | يحتاج أمر ripple delete غير موجود (§0.3) |
| Speed | من Inspector: 0.25×–4× | `clip.set_speed` | خيارات preset + حقل رقمي |

**حدود trim:** عند الوصول لحد المصدر يتوقف السحب مع مؤشر `◧`؛ لا رسالة خطأ (سلوك متوقع). عند محاولة تقاطع مع مقطع مجاور يتوقف عند حد الجار ويظهر خط snap.

### 6.2 التشغيل مقابل السحب (mapping إلى العقد)

| النية | العقد | ملاحظة تصميمية |
| --- | --- | --- |
| `play` | `POST /preview/sessions {mode:"play"}` → `stream_url` (fMP4) | يبدأ البث بعد ≤ 400 ms؛ أثناء الانتظار يُعرض آخر إطار + شارة `تحضير التشغيل` |
| `pause` | إيقاف القراءة من الـ stream + الاحتفاظ بالإطار | لا إغلاق للجلسة (إعادة الفتح مكلفة) |
| scrub | `seek(tick)` + `GET frame?tick=` | تجميع الطلبات ≤ 40 Hz و«آخر طلب يفوز» (§4.3) |
| seek أثناء play | `seek` ثم استئناف القراءة | يُظهر الإطار الجديد فقط عند وصوله؛ لا قفزة بصرية |

**قاعدة الصدق البصري:** لا تُرسم أبداً صورة مُصنَّعة محلياً على أنها «الإطار الحالي». أثناء الانتظار يُعرض **آخر إطار وصل** مع شارة صغيرة `◌` في زاوية الـ viewer. التوهّم البصري أثناء scrub أسوأ من تأخير 120 ms.

### 6.3 أثناء السحب (scrub) — الحالات الدقيقة

```text
pointer down ──► seeking(t) ──frame arrived──► ready(t)      [< 120ms]
                     │
                     └──> 120ms بلا وصول ──► chip «جارٍ الرسم» (لا يحجب)
                                              └── 1.5s ──► chip «المعاينة بطيئة» + رابط Quality
```

- عند السحب لا صوت (المسار الصوتي غير مضمّن في أوضاع scrub).
- السحب على مسار مقفل أو مقطع معطّل: يعرض الناتج المُركَّب الفعلي (ما سيُصدَّر).
- عند `missing asset`: يُعرض إطار أسود + badge `أصل مفقود` داخل الـ viewer، لا تعطيل للسحب.

### 6.4 الأخطاء والاستعادة

| المعرّف | الحالة | العرض والإجراء |

| `PV-ERR-02` | `PREVIEW_UNKNOWN` (جلسة منتهية) | إعادة إنشاء صامتة؛ لا رسالة للمستخدم |
| `PV-ERR-03` | `ENGINE_TIMEOUT` | chip `المحرك بطيء` + اقتراح تقليل دقة المعاينة |
| `PV-WARN-01` | `degraded: preview_hw_decode` | سطر واحد في شريط الحالة، بلا حوار |

### 7.5 الفحص المسبق (Pre-flight)

| # | الفحص | شدّة | الإجراء المتاح |
| --- | --- | --- | --- |
| 1 | أصول مفقودة | حاجب | `إصلاح relink` ينقل إلى أول مقطع مفقود |
| 2 | مساحة قرص < 1.5× التقدير | حاجب | `تغيير المجلد` |
| 3 | ملف ناتج موجود و`overwrite=false` | حاجب | `استبدال` (يضبط الحقل) أو `تغيير الاسم` |

### 7.6 التقدّم

| حالة العقد (§4.6) | التسمية العربية | مصدر التقدم |
| --- | --- | --- |
| `queued` | في الانتظار | لا شريط (نقطة) |
| `preparing` | تحضير | 0–5% تقديري |
| `rendering` | رسم الإطارات | `frames_done / frames_total` |
| `encoding` | ترميز | 95–99% (لا يُخفى أن التأخير هنا طبيعي) |
| `finalizing` | إنهاء الملف | 99% |
| `succeeded` | تم | 100% |
| `failed` | فشل | — |
| `cancelled` | أُلغي | — |
| `interrupted` | توقف غير متوقع | — |

**قواعد ETA:**

1. لا يُعرض ETA قبل 5 ثوانٍ من `rendering` أو قبل 10%.
2. يُعرض بصيغة مدى (`~3–5 د`) لا رقم واحد.
3. إذا تجاوز التباين 30% خلال آخر 30 ثانية → `—` (صدق صريح، نفس مبدأ §د.6).

**الإجراءات:** `إلغاء` (بتأكيد واحد فقط إن تجاوز 10%: «سيُحذف الملف الجزئي»)؛ **لا `Pause` في v1** (OQ-7 لم يُحسم؛ عرضه كزر معطّل مع سبب أسوأ من غيابه).

### 7.7 التصدير في الخلفية

- يمكن تصغير الحوار إلى شريط الحالة ومتابعة التحرير.
- banner دائم: `التصدير يعكس revision 218`.
- إذا زاد `revision` أثناء التصدير: تُضاف سطر `تعديلاتك الجديدة لن تُضمَّن` مع زر `تصدير نسخة محدثة` (يفتح حواراً جديداً؛ لا يوقف الحالي).
- حد التزامن: مهمتان في الطابور كحد أقصى (§5.4)؛ الثالثة تُرفض بـ `RESOURCE_QUEUE_FULL` ورسالة صريحة.

| `EX-OK-01` | نجاح | `تم التصدير` + الحجم + المدة + المسار؛ أزرار: `فتح الملف`، `فتح المجلد`، `تصدير آخر` |
| `EX-ERR-01` | `MEDIA_ASSET_MISSING` | «أصل مفقود: intro-4k.mp4» + `relink` + `إعادة المحاولة` |
| `EX-ERR-02` | `DISK_FULL` | «المساحة غير كافية» + `تغيير المجلد`؛ حذف الملف الجزئي معروض |
| `EX-ERR-03` | `OUTPUT_EXISTS` | «الملف موجود» + `استبدال` / `اسم جديد` |
| `EX-ERR-04` | `ENGINE_CRASH` | «توقف محرك التصدير» + `إعادة المحاولة` (محاولة واحدة تلقائياً ثم يدوي) |
| `EX-ERR-05` | `ENGINE_UNREACHABLE` | «فقدنا الاتصال بمحرك الوسائط» + `إعادة التشغيل` |
| `EX-ERR-06` | `ENGINE_TIMEOUT` | «تجاوز المحرك المهلة» + `تقليل الدقة` كإجراء مقترح |
| `EX-ERR-07` | `MEDIA_UNSUPPORTED` | «ترميز غير مدعوم» + `استخدام H.264` |
| `EX-ERR-08` | `RESOURCE_QUEUE_FULL` | «طابور التصدير ممتلئ» + `عرض المهام` |
| `EX-REC-01` | `interrupted` بعد إغلاق التطبيق | بانر عند الفتح: `تصدير لم يكتمل` + `استئناف` (حد محاولتين) + `تجاهل` |

نمط رسالة الفشل (ثابت لكل الأخطاء):

```
[ رمز أيقونة ]  عنوان بشري قصير
               سبب واحد محتمل (بلا مصطلحات داخلية)
               [ إجراء أساسي ]   [ إجراء ثانوي ]   التفاصيل ›
```

`التفاصيل` يفتح `code` و`correlation_id` و`instance` فقط — لا stack traces (§7.3).

| الحالة | العرض |
| --- | --- |
| مهمة واحدة | شريط تقدم واحد في الحوار |
| مهمتان | قائمة مصغرة داخل الحوار (اسم الملف + الحالة + إلغاء لكل صف) |

## 8. السطوح المساندة (باختصار)

### 8.1 الاستيراد وMedia bin

- **إفلات ملفات** على النافذة: overlay كامل `أفلت لإضافة الوسائط`.
- صف استيراد: اسم، نسبة، حالة (`probing` → `ready`)، وشريحة `proxy` عند الجاهزية.
- تكرار بنفس `source_hash`: لا صف جديد؛ toast `الملف موجود بالفعل` (dedupe من §4.2).
- VFR: تحذير سطر واحد `سيُطبَّع إلى 30fps`.
- unsupported: يُدرج في قائمة `rejected` داخل الحوار، لا يفشل الدفعة كلها.
- bin: grid/list، بحث فوري، شارات: مفقود (danger)، proxy (muted)، مدة.

### 8.2 Inspector (سياقي)

| التحديد | الحقول | الأمر |
| --- | --- | --- |
| Clip (فيديو) | Transform، Opacity، Speed، Volume، Blend | `clip.set_props` / `clip.set_speed` |
| Clip (صوت) | Gain (dB)، Fade in/out، Pan (على المسار) | `clip.set_props` |
| Track | Volume، Pan، Mute/Solo/Lock | `track.set_state` |
| Text | المحتوى، الخط، الحجم، اللون، المحاذاة، الحركة | `text.update` |
| Sequence | الدقة، fps، الخلفية | `sequence.rename` + إعدادات إنشاء |

الحقول الرقمية قابلة للسحب الأفقي (scrub)؛ خطوة drag = قيمة واحدة؛ `Shift` = ×10.

### 8.3 تحرير النص العربي

1. الكتابة في حقل النص تُظهر **overlay محلياً بخط Flutter** موسوماً `معاينة تقريبية` (debounce 300 ms).
2. بعد 300 ms يُطلب raster من الخلفية؛ عند وصوله يُستبدل الـ overlay ويُرفع الوسم.
3. لا يُسمح بتصدير قبل وصول rasters كل الطبقات؛ التصدير ينتظر (`preparing`).
4. المحاذاة الافتراضية `center` + `RTL`، واتجاه النص يتبع أول محرف قوي (bidi).

**قرار UX-3 (مسجّل):** overlay محلي مؤقت مقابل حجب الكتابة حتى يصل الـ raster. البديل المرفوض: حجب الكتابة — يجعل الكتابة العربية بطيئة وغير قابلة للاستخدام عند 300 ms، وهو أسوأ من معاينة تقريبية موسومة بوضوح.

### 8.4 مراجعة مقترح AI

- تظهر المقترحات في تبويب `مقترحات` في اللوحة اليسرى + شارة عدّاد.
- كل مقترح: نوعه، مداه الزمني، عدد التعديلات، ملخص، وزر `مراجعة`.
- `مراجعة` تفتح رؤية على الـ timeline (markers/captions معروضة كطبقة معاينة) + `تطبيق` / `تجاهل`.
- `تطبيق` يستخدم `If-Match: base_revision`؛ عند `STALE_PROPOSAL` يُعرض: `تغيّر المشروع منذ بناء المقترح` + `إعادة الحساب` / `إلغاء`.
- لا مفتاح AI: بطاقة واحدة `أضف مفتاحاً لتشغيل الذكاء الاصطناعي` + رابط الإعدادات؛ لا أزرار معطّلة صامتة.

### 8.5 الإعدادات

| القسم | ما يُضبط |
| --- | --- |
| عام | اللغة، السمة (داكن/فاتح/النظام)، مقياس الواجهة |
| وسائط | سياسة proxy، حد الكاش (GB)، مجلد الكاش |
| تصدير | المجلد الافتراضي، preset افتراضي، faststart |
| AI | المزود، المفتاح (keychain)، السقف الشهري |
| تشخيص | إصدارات المحرك، حالة GPU، فتح مجلد السجلات، تصدير تقرير |

## 11. RTL والنصوص الدقيقة (Microcopy)

| القاعدة | التطبيق |
| --- | --- |
| بذرة الاتجاه | `Directionality.of == rtl` افتراضياً؛ عناصر الـ timeline تُلفّ بـ `LTR` صريح |
| الأرقام | دائماً `LTR` معزولة؛ لا تحويل إلى أرقام هندية |
| التايم كود | `HH:MM:SS:FF`؛ الفاصل `:` ثابت في الاتجاهين |
| أيقونات | تُمرَّر عند RTL عدا: تشغيل، إيقاف، إطار سابق/تالٍ (محور زمني LTR) |
| النص المختلط | أسماء ملفات إنجليزية تُلفّ بـ `U+2066…U+2069` لمنع كسر السطر |
| الجمع | العربية: 1 «مقطع»، 2 «مقطعان»، 3–10 «مقاطع»، 11+ «مقطعاً» — عبر ICU plurals |
| الأخطاء | فعل مبني للمعلوم + سبب محتمل واحد |
| الأزرار | فعل أمر قصير: «تصدير»، «إعادة المحاولة»، «إلغاء» |

**مصطلحات موحّدة:** مقطع (Clip)، مسار (Track)، تسلسل (Sequence)، انتقال (Transition)، مؤثر (Effect)، معاينة (Preview)، تصدير (Export)، مشروع (Project)، أصل (Asset).
