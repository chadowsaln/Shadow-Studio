# UX-P1 — نموذج تفاعلي للـ Timeline والتصدير

نموذج قابل للنقر (نحو 60 ثانية للتحميل، بلا بناء ولا تبعيات) لسطحَي **S1 Timeline** و**S3 Export** كما وصفهما [SS-UX-001](../../docs/design/MVP-UI-UX-SPEC-v1.0.md)، ليكون صالحاً لاختبار **T1–T4** في §13.2 قبل كتابة Flutter.

النموذج **لا يتصل بمحرك**: لا preview حقيقي ولا تصدير حقيقي. كل ما هو محاكى معلَّم أدناه، وكل قرار تفاعلي يأتي من الوثيقة لا من الارتجال.

## التشغيل

```bash
python3 prototype/ux-p1/serve.py          # http://127.0.0.1:8137/index.html
python3 prototype/ux-p1/serve.py 9000     # منفذ آخر
```

الخادم يرسل `Cache-Control: no-store` حتى تظهر كل تعديلات الملفات عند التحديث.

| الملف | الدور |
| --- | --- |
| [index.html](index.html) | الهيكل: top bar، مكتبة، معاينة، timeline، مفتش، شريط حالة، حوارا التصدير والاستيراد |
| [styles.css](styles.css) | رموز §2.1 (نفس hex ونفس أزواج التباين)، طباعة Cairo + IBM Plex Mono، تخطيط §3.1 |
| [core.js](core.js) | الحالة، المعاينة، النقل (transport)، التراجع، المفتش، الحفظ |
| [timeline.js](timeline.js) | الرسم والتفاعل: zoom، snap، سحب/إفلات، ripple، trim، split/join، تحديد، كيبورد |
| [export.js](export.js) | المكتبة والاستيراد، حوار التصدير (preset/preflight/تقدّم/فشل/طابور)، شريط الحالة، أدوات الميسّر |
| [serve.py](serve.py) | خادم محلي بلا كاش |

## ما هو حقيقي وما هو محاكاة

| حقيقي | محاكاة |
| --- | --- |
| كل تفاعلات الـ timeline: تحديد، سحب مع snap وخط دليل، إدراج بإزاحة (ripple) يحفظ الخطوات في تراجع واحد، trim بحدود المصدر والجار، split/join/delete، zoom حول المؤشر، Fit/Zoom to selection، marquee | إطارات المعاينة: تدرّج لوني لكل أصل + اسمه وتايم كوده، لا فك ترميز |
| منطق الـ keyframes في مفتش المؤثر (0→0.5 خلال 2s ثم يثبت) كوصف للعقد | تأخير الإطار: محاكاة 80–140ms لإظهار شارة `◌` وchip «جارٍ الرسم» |
| قواعد §7 كاملة: تقدير الحجم، pre-flight (حاجب/تحذير/معلومة)، تعطيل زر التصدير عند الحاجب فقط، مراحل `preparing/rendering/encoding/finalizing`، ETA مدى بعد 5s/10% أو `—`، إلغاء بتأكيد فوق 10%، تصغير إلى شريط الحالة، «لن تُضمَّن» عند تغيّر revision، طابور مهمتين و`RESOURCE_QUEUE_FULL`، رسائل الفشل الثمانية، استئناف بعد انقطاع | تقدّم التصدير: مؤقت يقطع المراحل لا ترميز فعلي |
| RTL كامل مع محور زمني LTR، أرقام وتايم كود معزولة LTR، تباين الرموز، focus ring، `prefers-reduced-motion` | الذكاء الاصطناعي والمفاتيح والإعدادات: سطح واحد فقط كما في §8.5 |

## أدوات الميسّر

`Ctrl/Cmd + Shift + D` يفتح/يغلق لوحة الحالات. كل زر يسلّح حالة تُستهلك مرة واحدة عند التشغيل التالي:

| الزر | الأثر في النموذج |
| --- | --- |
| أصل مفقود | مقطع V1 يصبح بإطار `danger` + شارة في الـ viewer + pre-flight حاجب + `relink` في المفتش Pre-flight |
| قرص ممتلئ | حاجب في pre-flight + إجراء `تغيير المجلد` يغيّر مجلد الناتج |
| ملف موجود | حاجب `OUTPUT_EXISTS` + `استبدال` يغيّر الاسم إلى `final-v4.mp4` |
| انهيار المحرك | فشل عند 55% برسالة `ENGINE_CRASH` |
| مهلة المحرك | فشل عند 62% برسالة `ENGINE_TIMEOUT` |
| ترميز غير مدعوم | فشل عند 30% برسالة `MEDIA_UNSUPPORTED` |
| طابور ممتلئ | يرفض البدء بـ `RESOURCE_QUEUE_FULL` |
| تصدير منقطع | بانر `EX-REC-01` أعلى النافذة: `استئناف` (يعيد فتح الحوار ويبدأ) أو `تجاهل` |
| محرك بطيء | يطيل زمن الإطارات ويحوّل الـ ETA إلى `—` (صدق الانتظار) |
| إعادة الضبط | يعيد تحميل النموذج بحالة البداية |

## سكربت الاختبار (من §13.2)

اعطِ المشارك بطاقة المهمة فقط، ولا تشرح الواجهة. سجّل: الزمن، عدد طلبات المساعدة، وأي «قصد خاطئ» (سحب لغير المكان المقصود).

| # | بطاقة المهمة | مسار النموذج | ما نلاحظه |
| --- | --- | --- | --- |
| T1 | «استورد ملفين وأضفهما إلى مسارين» | `استيراد` → `تم`، ثم اسحب من المكتبة إلى مسار، أو انقر مزدوجاً | هل يفهم أن المكتبة مصدر؟ هل يحاول الإفلات فوق مقطع (يفتح مسار ripple)؟ |
| T2 | «اقصص مقطعاً عند رأس التشغيل ثم أعد الوصلة» | انقر المقطع → `S` (أو `قصّ`)، ثم حدّد القطعتين بـ `Shift` → `Ctrl+J` | هل يجد القصّ بلا زر أوضح؟ هل يفهم أن الوصل يشترط نفس الأصل؟ |
| T3 | «اكتب عنواناً عربياً وضعه فوق الفيديو» | انقر طبقة T1 → اكتب في «النص» → لاحظ وسم «معاينة تقريبية» ثم اختفاءه | هل الوسم مفهوم أم يظنه خطأ؟ هل التشكيل مقروء؟ |
| T4 | «صدّر 1080p إلى مجلد آخر» | `تصدير` (أو `Ctrl+E`) → preset 1080p → `خيارات متقدمة` → `Range` → `تصدير` | هل يقرأ الحاجب/التحذير؟ هل ينتظر ETA؟ هل يحاول الإلغاء فوق 10%؟ |
| T5 (اختياري) | «أغلق التطبيق أثناء التصدير ثم استعد» | أدوات الميسّر → «تصدير منقطع» → بانر `استئناف` | هل يجد الاستئناف بلا مساعدة؟ |

بعد الجلسة، القرارات المفتوحة في §15 التي يحتاجها هذا النموذج: **UQ-1** (هل يُقبل ripple كسلوك افتراضي؟)، **UQ-3** (حد العرض الأدنى للمقطع)، **UQ-7** (عرض عدد الإطارات)، **UQ-8** (preset افتراضي حسب المنصة).

## فجوات معروفة في النموذج

- **المعاينة ليست بثاً**: لا `POST /preview/sessions` ولا انتظار إطار حقيقي؛ شارة `◌` موجودة لكن مصدرها مؤقت.
- **الـ ripple داخل المسار نفسه فقط**؛ السحب عبر مسارات مختلفة ينقل المقطع ويُدرج إذا لزم، لكن إزاحة عدة مسارات معاً غير مطبَّقة (مؤجّل في §0.3).
- **لا حوارات مؤكدة للحذف** (الحذف قابل للتراجع، §P3) ولا ripple delete (غير معروض أصلاً).
- **التصدير محاكى**: لا ملف ناتج، وأزرار «فتح الملف/المجلد» تعرض toast فقط.
- **AI**: بطاقة CTA واقتراحان ثابتان؛ لا مفتاح ولا مهام.
- **Inspector جزئي**: Transform للقراءة فقط، Opacity/Gain/Speed/النص تعمل، لا keyframe editor (خارج النطاق §0.3).
- **لم يُختبر على Windows بعد**؛ يعتمد على متصفح حديث (Chromium/Firefox) وCSS `color-mix` و`<dialog>`.
